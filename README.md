# Motin AI — единый сайт

Единый проект Motin AI: главная страница, ИИ-чат /chat, анализ и генерация изображений, работа с PPTX и услуги лидогенерации Motin Group.

## Архитектура
- Next.js 16 + React 19, TypeScript.
- / — премиальная главная Motin AI, возможности, лидогенерация Motin Group, тарифы.
- /chat — текстовый диалог, вложения, изображения и PowerPoint.
- /api/chat, /api/images, /api/vision, /api/presentations, /api/files/* — перенесено из Lidia-ai-v1.
- /api/leads — форма заявки с отправкой в Telegram **только при заданных секретах**.

## Локально
1. Установить Node 22+.
2. npm install
3. Скопировать .env.example в .env.local и заполнить только локально.
4. npm run dev — сайт http://localhost:3000, чат /chat.
5. npm run build — проверить сборку без секретов.

## Cloudflare Workers
- Используется OpenNext адаптер с wrangler.jsonc (имя Worker: motin-ai).
- npm run preview — локальная проверка Worker runtime.
- npm run deploy — публикация **только после проверки на тестовом адресе**.
- В Cloudflare Dashboard настроить Runtime variables and secrets: OPENAI_API_KEY, CLOUDFLARE_ACCOUNT_ID, CLOUDFLARE_AI_TOKEN, LEADS_TELEGRAM_BOT_TOKEN, LEADS_TELEGRAM_CHAT_ID, FILE_LINK_SECRET (случайное значение 32+ символов).
- Не добавлять секреты в GitHub и не выводить их в логи.
- Перед окончательной публикацией проверить доступность motin-ai.pravosudov1994.workers.dev: имя Worker и поддомен аккаунта определяют фактический адрес.
- Старые адреса перенаправлять только после проверки всех функций и согласования.
- Фото /motin-hero.svg является временной стилизованной иллюстрацией; замените на созданный реалистичный portrait /public/motin-hero.webp после утверждения.

## Важные блокеры перед публичным запуском
- Для /api/files/[id] включены подписанные ссылки с ограниченным временем действия. Перед запуском установить FILE_LINK_SECRET и проверить скачивание/удаление; для персональных кабинетов дополнительно потребуется полноценная авторизация.
- Добавлены базовые per-instance ограничения для AI-эндпоинтов, но перед публичным запуском всё равно нужны Cloudflare WAF/Turnstile, распределённые лимиты и квоты, обработка ошибок и логи без персональных данных.
- Протестировать реальные OpenAI/Cloudflare токены, генерацию и скачивание PPTX, обработку файлов, мобильную клавиатуру.
- Проверить Next.js/OpenNext build и Worker preview на корректность всех API-обработчиков.

- Проверить актуальность цен, маркетинговых заявлений, юр. информацию и документы о конфиденциальности.

## Первая публикация в Cloudflare

В Cloudflare Workers & Pages создайте отдельный проект `motin-ai`, связанный с репозиторием `pravosudov1994-god/Lidia-ai`, и выберите **production branch `motin-ai-unified`**. Сборка: `npx opennextjs-cloudflare build`. Публикация: `npx opennextjs-cloudflare deploy`. Корневая папка: `/`. Первоначальная попытка с веткой `main` не может собрать OpenNext, потому что в `main` остаётся прежний статический сайт. Не переключайте production на `main`.

Завершение сборки не означает готовность AI: ключи, ограничения расходов, проверка пользовательских файлов и юридические документы обязательны до открытия сервиса широкой публике.

## Workers AI — текстовый чат без внешнего API-ключа
- Новый Worker имеет нативные привязки `AI`, `MOTIN_AI_RATE_PER_CLIENT` и `MOTIN_AI_RATE_GLOBAL` в `wrangler.jsonc`. Они применяются автоматически во время публикации OpenNext.
- Без `OPENAI_API_KEY` чат работает на Cloudflare `@cf/google/gemma-4-26b-a4b-it` в **текстовом режиме**. Если позже задан `OPENAI_API_KEY`, продолжает действовать существующий OpenAI-путь.
- Для бесплатного режима установлен **fail-closed** контроль: максимум 4 обращения в минуту на IP и максимум 20 обращений в минуту на локацию Cloudflare; не более 450 токенов ответа, 8 последних сообщений и 5000 символов текста. Файлы и изображения в этом пути не интерпретируются.
- **Важно:** встроенный Rate Limiting API учитывает лимиты по локациям, а НЕ устанавливает глобальный суточный/денежный предел. Для полного ограничения расходов необходим отдельный бюджетный контроль и проверка тарифного плана. Проверяйте фактическое потребление в Workers AI.
- `/api/cloudflare-status` показывает готовность нативной AI-привязки отдельно от необязательных REST-токенов Cloudflare.

## Typography / премиальный типографический стиль
- Единая система: Manrope (навигация, заголовки, текст, формы, чат) + Cormorant Garamond (только выразительные акценты, нумерация).
- Шрифты подгружаются из Google Fonts через layout; предусмотрены системные fallback и поддержка кириллицы.
- Правила размеров, межстрочных интервалов, кернинга и мобильной типографики централизованы в `app/typography.css`, который импортируется после остальных стилей.
